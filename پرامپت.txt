# 58. QML Strictness

در QML:

* Syntax را دقیق بررسی کن.
* Semicolonهای نامعتبر را حذف کن.
* Duplicate Property را حذف کن.
* Unknown Module را استفاده نکن.
* Unsupported Import را استفاده نکن.
* APIهایی که در QField 4.3.3 وجود ندارند استفاده نکن.

قبل از تحویل:

QML Parse Check

اجرا کن.

هیچ:

Unexpected token
Property value set multiple times
module not installed
Unknown property
Unknown signal

نباید باقی بماند.
